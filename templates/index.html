📖 What just happened?

  • Docker started from a Python base image.
  • pip installed Flask from requirements.txt.
  • The container ran python app.py.
  • Flask answers on port 5000.

💡 Remember

  • Python needs no compilation.
  • requirements.txt = shopping list of libraries.
  • RUN = at build time, ENTRYPOINT = at start.

⌨ Commands used in this project

# build the image and run the container
docker build -t python-flask-app .
docker run -d -p 5000:5000 python-flask-app
# when something is wrong
docker logs <container-id>
docker exec -it <container-id> /bin/bash
